# Cloud Concepts Reflection

In my daily life, I regularly use several cloud-based services without always realizing that they are powered by cloud computing technologies. Three services I frequently use are Google Drive, Facebook Messenger, and Canva.

Google Drive is an example of Software as a Service (SaaS) because I access storage and document tools directly through a web browser without managing any servers or infrastructure. Its deployment model is Public Cloud since Google provides the service to millions of users over the internet.

Facebook Messenger is also classified as SaaS because users simply use the messaging application while Meta manages the entire platform, infrastructure, and updates. It operates on a Public Cloud deployment model because it is available to the general public online.

Canva is another SaaS application because it provides design tools through the cloud, allowing users to create and save projects online. Its deployment model is Public Cloud since the service is shared among many users worldwide.

Version control is extremely important in cloud projects because cloud infrastructure can change frequently. A small mistake in configuration files or deployment scripts may affect an entire system. Using Git allows developers to track every change, compare versions, and restore previous working configurations when problems occur.

GitHub improves collaboration by enabling multiple team members to work on the same project without overwriting each other’s work. Features such as branches, pull requests, and commit history help teams review changes before they are applied. This process reduces errors, increases accountability, and makes cloud infrastructure management more organized and reliable.

Overall, this activity helped me realize that cloud computing is already part of my everyday life and that Git and GitHub are essential tools for managing cloud resources professionally.
